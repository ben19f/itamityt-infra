# И там и тут (itamityt.ru)

**Описание проекта:**  
«И там и тут» — это сервис **link-in-bio**, который позволяет пользователям собирать все свои онлайн-ссылки 
на одной странице. Сервис удобен не только разработчикам, но и широкой аудитории: блогерам, 
предпринимателям, инфлюенсерам и просто активным пользователям интернета.

Пользователь может:

- зарегистрироваться и создать персональную страницу
- добавлять ссылки на социальные сети, сайты, мессенджеры
- получать короткий URL и QR-код для публикации
- просматривать статистику переходов по ссылкам (в будущем)

---

## Архитектура проекта

Проект разделен на микросервисы для демонстрации современных DevOps-подходов:

### 1️⃣ Frontend
- Статический сайт для отображения страниц пользователей
- Контейнеризован через Nginx
- Возможность интеграции SPA на React/Vue

### 2️⃣ Backend API
- Обрабатывает регистрацию, авторизацию, управление ссылками, статистику переходов
- Написан на Python + FastAPI
- Контейнеризован для Kubernetes

### 3️⃣ Redirect Service
- Отвечает за короткие ссылки (`itamityt.ru/l/abc123`)
- Сохраняет статистику переходов
- Делает редирект на оригинальный URL

### 4️⃣ Worker
- Фоновая обработка задач:
  - агрегирование статистики
  - удаление устаревших данных
  - подготовка аналитики

### 5️⃣ Database
- PostgreSQL (можно использовать локальный сервер или managed сервис)
- Таблицы:
  - `users` — информация о пользователях
  - `links` — ссылки пользователей
  - `clicks` — статистика переходов

### 6️⃣ Monitoring
- Prometheus — сбор метрик
- Grafana — визуализация и дашборды
- Loki — агрегация логов

### 7️⃣ Infrastructure
- Docker для контейнеризации
- Kubernetes для оркестрации (frontend, backend, redirect, worker)
- Ingress для публичного доступа
- CI/CD pipeline (GitHub Actions) для автоматического деплоя при коммите

## Roadmap (DevOps-портфолио)

Проект делится на несколько этапов развития, показывающих навыки DevOps:

### Этап 1 — Подготовка инфраструктуры
- Создание Git-репозитория
- Определение архитектуры сервисов
- Настройка Docker контейнеров
- Настройка Kubernetes кластера (home lab + VPS)
- Настройка ingress для публичного доступа

### Этап 2 — MVP сервиса
- Backend API: регистрация, авторизация, CRUD ссылки
- Frontend: отображение персональной страницы
- Redirect Service для коротких ссылок
- PostgreSQL для хранения данных

### Этап 3 — CI/CD
- Настройка GitHub Actions
- Автоматическая сборка Docker-образов
- Автоматический деплой в Kubernetes

### Этап 4 — Мониторинг и логирование
- Подключение Prometheus для сбора метрик
- Подключение Grafana для визуализации
- Loki для сбора логов и анализа ошибок

### Этап 5 — Расширение функционала
- Worker для фоновых задач (очистка устаревших ссылок, статистика)
- Статистика переходов (анализ по времени, географии)
- Генерация QR-кодов для страниц
- Кастомизация дизайна страницы
- Возможность подключать собственный домен

### Этап 6 — Масштабирование и оптимизация
- Горизонтальное масштабирование backend и worker сервисов
- Настройка autoscaling в Kubernetes
- Оптимизация нагрузки и очередей
- Резервное копирование базы данных
- Настройка SSL и безопасности
